# Demo tickets

These three tickets exist as **demo material** for showing a coding agent at
work. They describe real, desirable improvements to the board in the way a
product-minded colleague would file them — outcome and motivation first,
implementation deliberately left open — and they are **not implemented** on
purpose. Point the agent at one of these files and let it make the design
decisions:

1. `01-grid-browsing-experience.md` — frontend-only scope
2. `02-tag-discovery-and-spelling.md` — frontend + backend scope
3. `03-large-uploads-and-search-exclusions.md` — full-stack scope

The numbering reflects increasing scope and difficulty.
